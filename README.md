# Selfie Partículas 3D (Flutter) 🎥✨

Versão em Flutter do aplicativo de partículas 3D com câmera em tempo real.

## 🤖 Build Automático via GitHub Actions (CI/CD)
Este repositório possui uma pipeline de CI/CD configurada em `.github/workflows/build_apk.yml`. 
Assim que você envia o código para o GitHub, o servidor do GitHub Actions compila o APK do Android automaticamente com o Android SDK e Gradle, disponibilizando o arquivo `.apk` para download na aba **Actions** (Artifacts).

## 🚀 Como Executar
1. Instale o [Flutter SDK](https://flutter.dev/).
2. Execute `flutter pub get`.
3. Execute `flutter run`.
